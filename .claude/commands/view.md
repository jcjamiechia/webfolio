Run the Flutter web app locally for preview.

Execute the following command in the project directory to launch the website on a local development server:

```
flutter run -d chrome --web-port 8080
```

Run this command using Bash. If port 8080 is already in use, try port 8081 instead. Run the command in the background so the user can continue working.

After launching, tell the user the URL (http://localhost:8080) and that they can stop the server by pressing `q` in the terminal or by asking you to stop it.
